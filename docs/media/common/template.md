神经网络之反向传播：让机器学会思考的秘密
大家好，我是小扬，我们一起学AI。

上篇文章《一文彻底了解神经网络之感知机》，我们了解了什么是感知机，以及如何训练一个感知机。但是感知机存在一个致命的问题，就是它只能解决线性可分的问题。

为了解决非线性可分的问题，必须要引入多层感知机（MLP），而要引入多层感知机，必须要解决隐藏层的权重调整问题，即输出层的误差怎么“传递”回去，指导隐藏层的学习？

这里的核心就是反向传播算法，接下来我们一起来了解这个算法是如何将输出的误差传递回去的。

先看下神经网络的图结构，如下，有输入层、隐藏层和输出层。

图片
我们可以把神经网络想象成一个多工位的厨房流水线。

输入层可以理解成是厨房的“配菜区”，假如我们的任务是识别一张图片是不是猫？那图片的像素点对应的就是“食材”，被送进输入层。

隐藏层可以理解成是“烹饪区”，由多个厨师（称为“神经元”）组成。每个厨师负责一道工序，比如有的负责识别“胡须”，有的负责识别“耳朵”，有的负责识别“爪子”。他们将前一个工位处理过的半成品进行加工。每个厨师都有一套自己的秘方（称为“权重”），以及自己独特的调料（称为“偏置”）。

输出层是“出餐口”，最后的总厨师根据前面所有工序的结果，做出最终判断，比如输出一个数字“0.9”，表示“我有90%的把握这是一只猫”。

这个从“食材”到“出餐”的过程，就是神经网络的“前向传播”。

但问题来了，现在我们假设一开始厨师什么都不会，他们的“秘方”（权重）都是随机的，做出来的“菜”（预测结果）肯定难吃的要命。比如，你给一张猫的图片，它告诉你“这张图片是狗的概率是90%”。

我们该如何教会这群厨师，让他们不断地改进厨艺，直到满意为止呢？

答案就是 —— “反向传播”。

现在我们有一群“美食评论家”，出餐口出一道菜后，由这些“美食评论家”来给出反馈，指出这道菜和预期差了多少。

在AI里，这个差了多少，专业术语叫“损失或误差”，计算这个损失和误差的叫“损失函数”，比如“均方误差MSE”。

损失越大，说明AI厨师做得越离谱。我们的目标就是要让这个损失变得尽可能的小。

那现在明确知道损失是多大了，但是怎么知道问题出在谁身上呢？

我们可以从最后一道工序一步一步的往前推导，找出这个责任到底出在谁身上，这个“责任”在数学上就是“梯度“。

梯度本质上指明了一个方向：我应该超哪个方向调整，才能让菜（损失）变的更好（更小）。

接下来，总厨师（输出层）会转身对上一道工序的“烘焙师”（隐藏层）说：“你给我的蛋糕胚太甜了，导致我最后的成品甜到发腻！根据我的计算，你对这次的‘甜度超标’负有70%的责任！”

这个“告诉下一级要负多少责任”的过程，就是误差的反向传播。烘焙师接到这个“甩锅”后，也会进行同样的操作：一部分是自己的责任（比如烤箱温度没设对），另一部分责任则要继续向前传递给更早的“面团搅拌师”。

这个责任链会一直反向追溯，直到厨房的“配菜区”（输入层）。这样，流水线上的每一个厨师，都明确知道了自己对最终的“失败作品”贡献了多大的“责任”（梯度）。

这个精妙的“责任分配”机制，在数学上是靠 “链式法则”（Chain Rule）‍ 实现的。这里我们不需要去深究怎么就实现了，只需要知道，链式法则就像一个完美的责任追溯系统，能精确计算出网络中每一个参数（权重和偏置）对最终总误差的贡献程度。

当每个厨师都拿到了自己的“责任报告”（梯度）后，他们就知道该如何改进了。

搅拌师”发现自己糖放多了，下次就少放一点。

“烘焙师”发现自己温度设高了，下次就调低一点。

“总厨师”发现自己盐加多了，下次就少加一点。

这个“调整一点”的动作，在AI里叫做 “权重更新”。他们会用自己的“责任”（梯度）乘以一个叫做 “学习率” 的小数值，然后从原来的“配方”（权重）中减掉它。

新配方 = 旧配方 - 学习率 × 责任大小。

学习率就像厨师的“谦虚程度”。学习率高，厨师就大刀阔斧地改配方，可能改过头；学习率低，厨师就小心翼翼地微调，学习过程会很慢。

好了，我们的厨房之旅到此结束。让我们回顾一下：

1.神经网络就像一个厨房流水线，通过前向传播来“做菜”（做出预测）。 2.损失函数是“美食评论家”，负责评价菜品和真实标准的差距。 3.反向传播是“事后追责”的过程，利用链式法则，将总误差的“责任”一层层地反向分配给每一个“厨师”（参数）。 4.梯度下降是“改进配方”的方法，每个厨师根据自己分到的责任（梯度），朝着让菜更好吃的方向，微调自己的操作（更新权重）。

如下图，这个 “试错-归因-修正” 的闭环，就是反向传播的精髓，也是深度学习能够自动学习和优化的核心所在。
