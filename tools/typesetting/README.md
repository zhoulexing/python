# Markdown实时渲染器

一个功能完整的在线Markdown编辑器，支持实时预览、同步滚动、语法高亮等功能。

## 功能特性

### 🚀 核心功能
- **实时预览**: 左侧编辑，右侧实时渲染显示
- **同步滚动**: 编辑器和预览窗口同步滚动
- **语法高亮**: 代码块支持多种编程语言高亮显示
- **响应式设计**: 支持桌面和移动设备

### ✨ 高级功能
- **全屏模式**: 支持编辑器和预览的全屏显示
- **导出HTML**: 将Markdown转换为独立的HTML文件
- **本地存储**: 自动保存编辑内容，刷新页面不丢失
- **复制到公众号**: 复制富文本内容，可直接粘贴到微信公众号编辑器，样式完全保持
- **复制到小红书**: 复制富文本内容，可直接粘贴到小红书编辑器，采用小红书风格样式
- **复制HTML**: 一键复制渲染后的HTML代码
- **打印预览**: 支持打印预览功能
- **统计信息**: 实时显示字符数和行数

### 📝 Markdown支持
- 标题 (H1-H6)
- 文本格式 (粗体、斜体、删除线)
- 列表 (有序、无序、嵌套)
- 链接和图片
- 引用块 (支持嵌套)
- 代码块和行内代码
- 表格
- 分割线
- 任务列表
- HTML标签

## 使用方法

### 基本使用
1. 在左侧编辑器中输入Markdown文本
2. 右侧会实时显示渲染结果
3. 支持滚动同步，编辑和预览同步滚动

### 快捷键
- `Ctrl/Cmd + S`: 保存内容到本地存储
- `Ctrl/Cmd + E`: 切换编辑器全屏模式
- `Ctrl/Cmd + P`: 切换预览全屏模式

### 工具栏功能
- **同步滚动**: 开启/关闭编辑器和预览的同步滚动
- **全屏编辑**: 切换到编辑器全屏模式
- **全屏预览**: 切换到预览全屏模式
- **导出HTML**: 将当前内容导出为HTML文件

### 面板操作
#### 编辑器面板
- **清空**: 清除所有编辑器内容
- **示例**: 加载Markdown语法示例

#### 预览面板
- **复制到公众号**: 复制富文本内容，专门为微信公众号编辑器优化的样式
- **复制到小红书**: 复制富文本内容，采用小红书风格的活泼样式设计
- **复制HTML**: 复制渲染后的HTML代码到剪贴板
- **打印**: 打开打印预览窗口

### 🔥 平台适配优化

#### 微信公众号适配
**复制到公众号**功能专门优化：
- 自动转换为内联样式，无需外部CSS
- 17px字体大小，适合公众号阅读
- 保持代码高亮、表格、引用等格式
- 支持标题、列表、链接等所有Markdown元素
- 兼容性处理，确保在微信编辑器中完美显示

#### 小红书适配
**复制到小红书**功能专门优化：
- 活泼年轻的配色方案
- 渐变标题和彩虹分割线
- 简洁清爽的列表样式
- 时尚的引用块和代码块样式
- 圆角图片和阴影效果
- 适合小红书用户群体的视觉风格

## 技术栈

- **HTML5**: 页面结构

## 自定义配置

### 修改主题
在 `style.css` 中的 `:root` 选择器中修改CSS变量：

```css
:root {
    --primary-color: #2563eb;    /* 主色调 */
    --bg-color: #f8fafc;         /* 背景色 */
    --surface-color: #ffffff;    /* 表面色 */
    --text-color: #1e293b;       /* 文本色 */
    /* ... 其他颜色变量 */
}
```

### 修改Markdown渲染配置
在 `script.js` 的 `initMarked()` 方法中修改marked配置：

```javascript
marked.setOptions({
    highlight: function(code, lang) { /* 语法高亮配置 */ },
    breaks: true,        // 换行转换
    gfm: true,          // GitHub风格Markdown
    tables: true,       // 表格支持
    sanitize: false     // HTML标签支持
});
```
